# MeowPlace

Sistem Informasi Penjualan Perlengkapan Hewan Peliharaan Menggunakan Konsep Pemrograman Berorientasi Objek (OOP).

## Struktur Proyek

- `Frontend/` : Antarmuka pengguna berbasis HTML, CSS, dan TypeScript dengan penerapan konsep OOP.
- `Backend/` : Layanan Web API berbasis C# (ASP.NET Core).

## Cara Menjalankan Frontend

```bash
cd Frontend
npm install
npm run build
```

Buka berkas `Frontend/index.html` melalui server lokal (misalnya ekstensi Live Server pada VS Code).
